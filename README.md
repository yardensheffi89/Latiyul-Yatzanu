# לטיול יצאנו

אפליקציית ווב לתכנון טיולים משפחתיים בישראל: מפה, פילטרים, כרטיס מסלול, המלצת השבוע ולינה.

- **קטלוג:** `data/catalog.json`. נוצר מגיליון הגוגל בעזרת `tools/gen_catalog.py`, ולא עורכים אותו ידנית.
- **מידע משפחתי:** Firebase (כניסה עם Google + Firestore). רק בני המשפחה רואים אותו.
- **בלי שלב בנייה:** HTML, CSS ו-JavaScript רגילים. Leaflet יושב בתוך `vendor/`.
- **הרצה מקומית:** `python3 -m http.server` ואז לפתוח את http://localhost:8000
